The app's two fonts, kept here so the site never loads anything from another
server (the Content Security Policy only allows the site's own fonts).

- Saira Condensed 600 and 700 (Latin), by Omnibus-Type, from Google Fonts:
  headings, the shop's name, prices and plates. Downloaded as woff2 from the
  @fontsource/saira-condensed 5.3.0 package.
- Inter (Latin, variable: every weight in one file), by Rasmus Andersson:
  everything else. Downloaded as woff2 from the @fontsource-variable/inter
  5.3.0 package.

License for both: SIL Open Font License 1.1, which allows using and sharing
them with the app.
